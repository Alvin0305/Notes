    Unsupervised Domain Adaptive Semantic Segmentation (UDA-SS)¶

    Term Meaning
    Unsupervised Target domain has no labels
    Domain Adaptation Transfer knowledge across datasets
    Semantic Segmentation Pixel level classification
    - Labeling segmentation data is expensive. Each image can take 30 to 90 minutes to annotate.
    ---

    Difference from other papers¶

    • Most research papers looked only at images, but in this one, Videos are also there
    • Which means, there is another dimension: TIME
    • Temporal Information is there: Object moves between frames.

    So, there are two separate problems: - Image domain adaptation - Video domain adaptation

    • They were addressed differently, handled differently as different problems. But based on this research paper, we should handle it as problems with same core issue Domain Distribution Shift**
    • This reduces duplicate work, inefficient research progress etc
    • This was the research gap for this paper

    The core idea of the paper¶

    • UDASS is introduced.
    • Create an unified framework for both image and video domain adaptation
    • This includes two key innovations, which are
      1. Quad-directional Mixup(QuadMix)
      2. Flow-guided spatio temporal aggregation
    Components¶
    • Source Images
    • Target Images
    • Source Videos
    • Target Videos

    Traditional research handles them separately, this paper merges them into one training framework

    Abstract¶

    Unsupervised Domain Adaptive Semantic Segmentation (UDA-SS) aims to transfer the supervision from a labeled source domain to an unlabeled and shifted target domain.

    Domain Images Labels
    Source domain synthetic images ✔ labeled
    Target domain real images ✘ unlabeled
    Dataset Type
    GTA5 synthetic driving scenes
    Cityscapes real street scenes
    - Train using synthetic labeled data
    - Adapt the model to real unlabeled data
    - This is Domain Adaptation
    Types of Domain Adaptation¶
    Type Target labels
    Supervised DA some labels exist
    Semi-supervised DA few labels exist
    Unsupervised DA no labels exist
    • We use Unsupervised Domain Adaptation in this paper
    Distribution Shift¶
    • Machine learning assumes that, Training and Test dataset follows the same probability distribution
    • But in domain adaptation, it's not.
    • Even if both contains cars, the pixel patterns are different.
    • This difference is called Distribution Shift.

    Why Domain Adaption in Video is more consistent¶

    • There is temporal information, which can be exploited by the model.
    • i.e., a car in frame 1 will most probably there in frame 2 with only small changes in its position.
    • This can be exploited for more consistent results.
    • For this, researchers use optical flow

    Methods used¶

    Data Augmentation¶

    Augmentation includes: - flip - rotate - crop - color jitter

    • These methods, will increase the dataset diversity.
    • The paper considers domain difference as a type of augmentation problem.
    • So, by augmenting the synthetic dataset, the dataset will be more similar to the real-life dataset.
    • This leads to the first major algorithm: QuadMix

    What is Mixup in General¶

    • Instead of training with image A and image B, we will create a synthetic hybrid.

    new image = 70% image A + 30% image B new label = 70% label A + 30% label B

    • This helps the model see the intermediate states between the classes.

    Challenge¶

    Mixup is difficult in segmentation, we don't just mix the labels like 70% dog + 30% cat. We must mix the pixel map. For this, researchers use CutMix

    CutMix¶
    • Instead of blending images, we cut a region from one image and paste it into the other.

    Image A = street Image B = car Result = street with car patch inserted.

    • This creates synthetic scenes making the segmentation model more robust.

    Our Domain Adaptation Problem¶

    Domain Labels
    Source labeled
    Target unlabeled
    1. Generate pseudo labels for target images.
    2. Mix source and target images.
    3. Train the model on the mixed result.

    There are 4 meaningful ways to mix data when 2 domains exists. This is where QuadMix comes.

    4 Directions of QuadMix¶

    There are 2 domains - Source - Target

    There are 4 possible combinations

    • Source -> Source
    • Mix two source images
    • regular augmentation
    • stabilizes training
    • these labels are reliable
    • Target -> Target
    • Mix two target images
    • But target images do not have ground truth labels.
    • So the model uses pseudo labels.
    • Pseudo labels are predictions generated by the model itself.
    • Source -> Target
    • Mix source image with target image.
    • The labeled source region injects trusted information into the target image.
    • Target -> Source
    • Mix target image into source image.
    • This was ignored in earlier work, but it powerful as it introduces target style features into labeled data.

    What this achieves¶

    Three things happen simultaneously.

    1. Strong supervision stays intact¶

    Source labels guide the learning.

    2. Target knowledge gradually emerges¶

    Pseudo labels improve over time. The model begins to self-teach.

    3. Domain gap shrinks¶
    • Because images contain mixtures of both domains.
    • Instead of two separate distributions:
    • Source -------- Target
    • The model sees intermediate states:
    • Source ---- hybrid ---- hybrid ---- Target

    The distribution bridge becomes smoother.

    It doesn't just mix the images, it mixes the features. In neural networks, image -> convolution layer -> feature maps -> classifier Feature maps contains - edges - shapes - object parts mixing at this level blends the semantic information, not just pixels. So, there is - image-space mixing - feature-space mixing

    Optical Flow - measuring pixel motion¶

    How did the pixel move between two frames?

    • Optical flow estimates the shift in the position of an object over time.
    • Mathematically, it produces a vector field. $$ \begin{aligned} F(x, y) &= (u, v) \ (x, y) &= \text{pixel location} \ u, v &= \text{movement in horizontal and vertical directions} \end{aligned} $$
    • Each pixel receives a arrow describing its motion.
    How it is useful?¶
    • If we got the correct segmentation of a car in frame 1.
    • And in frame 2, there is some lighting changes causing failure in properly segmenting the car
    • Using the optical flow, model can propagate the label forward in time.
    • Instead of guessing, it reuses the earlier info.
    • This makes the model more stable and make the pseudo labels better.

    Spatio-Temporal Aggregation¶

    Spatial -> Information across nearby pixels. Temporal -> Information across nearby frames. Aggregation -> combining information from multiple sources.

    Steps¶
    • The network extracts feature maps from each frame.
    • Optical flow estimates how the pixels move from t - 1 -> t and t + 1 -> t
    • Using the flow vector, features from neighboring frames are warped into coordinate space of frame t
    • All aligned (warped) features are then combined (aggregated)
    Uses¶
    • This self verifies the model output.
    • If a frames output is not consistent with the next frame, then it can be handled accordingly.

    QuadMix + Flow Aggregation¶

    QuadMix -> Domain Bridging -> reduces domain gap. Flow Aggregation -> Temporal Stability -> improves learning quality.

    UDASS Framework¶

    Input data
   │
   ├─ Source images (synthetic, labeled)
   ├─ Target images (real life, unlabeled)
   └─ Target videos
        │
        ▼
QuadMix data augmentation
(4 domain mixing directions)
        │
        ▼
Backbone segmentation network
        │
        ▼
Flow-guided temporal aggregation
(using optical flow)
        │
        ▼
Segmentation prediction
        │
        ▼
Training losses

    The system learns from - labeled synthetic images. - pseudo labeled real images. - temporal consistency across video frames.

    Core Idea¶

    • Data Mixing
    • Self Training
    • Temporal Consistency

    The network architecture¶

    input image
      ↓
backbone CNN / transformer
      ↓
feature maps
      ↓
segmentation head
      ↓
pixel-level class prediction

    the backbone can be - a convolutional network (ResNet style) - or a transformer segmentation model

    Training Data Streams¶

    • Source Images (synthetic, true labeled)
    • Target images (real life, not labeled)
    • Target video frames
    • Mixed samples produced by QuadMix
    Data type What it provides
    Source images reliable supervision
    Target images domain adaptation
    Target video temporal consistency
    QuadMix outputs domain bridging

    Using Pseudo Labels¶

    Since the target domain has no labels, the system generates pseudo labels. - i.e., model's prediction is used as training label - i.e., if the model predicts something as a car with around 95% confidence, then the model trust the prediction and use the prediction as a temporary label. - For proper error handling we need confidence filtering.

    Confidence Thresholding¶

    Only predictions having confidence above a threshold are used as pseudo labels.

    Loss Functions¶

    Neural networks learn through loss functions.

    Supervised Segmentation Loss¶
    • Applied on source images with ground truth labels.
    • Usually it is a cross-entropy loss
    • Which means: How different is predicted class probability from the true class?
    Pseudo Label Loss¶
    • Applied on target domain images using pseudo labels.
    • Same cross-entropy idea, but labels are model-generated
    • Since the labels are imperfect, they are filtered by the confidence threshold.
    Consistency Loss (Temporal Consistency)¶
    • How consistent is the prediction across time.
    • prediction(frame_t) = warped_prediction(frame_t-1)
    • If predictions disagree strongly, then loss increases

    Training Loop¶

    • Load source images and target images/videos
    • Generate pseudo labels for target domain
    • Apply QuadMix augmentation
    • Extract features using backbone network
    • Apply flow guided temporal aggregation
    • Compute losses
    • Update network parameters.

    We will repeat this.

    How Mixing is done¶

    Image Space¶
    • actual pixel mixing (CutMix style)
    Feature Space¶
    • Mixing inside neural network representations
    • Semantic patterns combine
    • network learns intermediate representations

    Evaluation Metric¶

    Semantic Segmentation models are evaluated using mIoU -> Mean Intersection over Union - For a single class, \(IoU = \frac{intersection}{union}\) - intersection = pixels predicted correctly - union = pixels predicted + actual pixels. \(IoU = \frac{\text{predicted car region } \cap \text{ true car region}}{\text{predicted car region } \cup \text{ true car region}}\) - Now we take the average across all the classes.

    mIoU Interpretation
    30–40 weak model
    40–50 decent
    50–60 strong
    60+ Best
    - 1 to 3% improvement is enough

    Baseline methods¶

    • Comparison with existing approaches are called baselines.
    • Baselines of this paper are:
      • adversarial domain adaptation
      • pseudo label self training
      • image mixing augmentation
      • temporal consistency models

    Ablation Study¶

    • This is the process of removing pieces of the algorithm to see their effect.
    • Checks whether a part is essential or not
    • Using this we can understand which part is contributing to the improvement

    Ablation Study showed, - QuadMix alone improves domain adaptation. - Temporal aggregation alone improves video segmentation. - Both together produce the best results

    Variant Description
    Baseline no adaptation
    + QuadMix mixing only
    + temporal aggregation motion only
    Full model everything combined
    Model mIoU
    Baseline lowest
    + QuadMix improvement
    + Temporal aggregation improvement
    Full model highest

    Maths¶

    Feature warping¶
    \[ F_{t - 1 \to t}(x, y) = F_{t - 1}(x + u, y + v) \]
    • F = feature map
    • (u, v) = flow vector
    Feature Aggregation¶
    \[ F_agg = \sum w_iF_i $$ - $F_i$ = warped features from nearby frames - $w_i$ = weights ##### Pseudo Label Refinement $$ L_{pseudo} = \begin{cases} prediction, & \text{if confidence } \gt \tau \\ ignored, & otherwise \end{cases}\\ $$ ##### Combined Training Loss $$L = L_{source} + L{pseudo} + L_{temporal}\]
    Loss Purpose
    Source loss supervised training
    Pseudo loss target domain learning
    Temporal loss frame consistency

    Limitations discussed in the paper¶

    Dependency on optical flow quality¶
    • If motion estimation is inaccurate, temporal aggregation can propagate errors.
    • Optical flow estimation itself is a difficult problem.
    Computational Cost¶
    • Video processing and feature aggregation increase computation.
    • Training becomes heavier than standard segmentation models.
    Still relies on synthetic datasets¶
    • Like most domain adaptation research, the experiments depend heavily on synthetic to real benchmarks.
    • Real world deployment might involve more complex domain shifts.
    Dependence on pseudo labels¶
    • If pseudo labels are poor early in training, error can propagate.

    Future Research¶

    Better cross domain augmentation¶
    • Quad Mix could be extended to other tasks like:
      • object detection
      • instance segmentation
      • depth estimation
    Stronger temporal modeling¶
    • Current method uses optical flow to aggregate features
    • Feature models could incorporate
      • Transformer based video reasoning
      • Long range temporal memory
      • Multi frame attention mechanisms
    Generalizing beyond synthetic to real adaptation¶
    • Weather changes
    • Camera sensor differences
    • Geographic variation
