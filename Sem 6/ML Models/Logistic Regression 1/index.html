    Logistic Regression 1

    Loss Function¶

    \[ \begin{aligned} L(f(x), y) &= \begin{cases} -\log(f(x)) & \text{y = 1} \\ -\log(1 - f(x)) & \text{y = 0}\\ \end{cases} \\ \\ \text{which can be simplified as} \\ L(f(x), y) &= -y \times\log(f(x)) - (1 - y) \times\log(1 - f(x)) \\ \\ \therefore\text{cost to minimise is:}\\ J(w, b) &= \frac{1}{m}\times\sum_{i = 1}^m{L(f(x^{(i)}, y^{(i)}))} \\ &= \frac{1}{m}\times\sum_{i = 1}^m{-y\times\log(f(x))) - (1 - y)\times\log(1 - f(x))} \\ &= -\frac{1}{m}\times\sum_{i = 1}^m{y\times\log(f(x)) + (1 - y)\times\log(1 - f(x))} \\ \\ \text{Likelihood} \\ P(y|x) &= \hat{y}^y\times(1 - \hat{y})^{1 - y} \\ L(w, b) &= \prod_{i = 1}^m{\hat{y_i}^{y_i}\times(1 - \hat{y_i})}^{1 - y_i} \\ log(L) &= \sum_{i = 1}^m{y_i\times\log(\hat{y_i}) + (1 - y_i)\times\log(1 - \hat{y_i})} \\ \therefore \text{for one point}, \\ l(y, \hat{y}) &= y\times\log(\hat{y}) + (1 - y)\times\log(1 - \hat{y}) \\ \text{and for a dataset} \\ J(w, b) &= \sum_{i = 1}^{m}{y_i\times\log(\hat{y_i}) + (1 - y_i)\times\log(1 - \hat{y_i)}} \end{aligned} \]

    Detailed below are the comprehensive notes for Logistic Regression, covering all aspects from the provided source materials, including mathematical foundations, optimization techniques, and regularization.

    1. Introduction and Core Concepts¶

    • Definition: Logistic regression is a supervised learning algorithm used for binary classification, where the target variable \(y\) can only be one of two values (e.g., 0/1, False/True, No/Yes).
    • Distinction from Linear Regression: While linear regression predicts continuous numerical values, logistic regression fits a line (or hyperplane) to best separate two classes.
    • Limitation of Linear Regression for Classification: Using linear regression for classification is problematic because:
      • Predictions can fall far outside the 0 to 1 range.
      • The model is highly sensitive to outliers; adding a single distant data point can shift the regression line and cause previously correct points to be misclassified.

    2. The Mathematical Model¶

    The Sigmoid (Logistic) Function¶

    To ensure the output is always between 0 and 1, the model uses the Sigmoid function, \(g(z)\):

    • Formula: \(g(z) = \frac{1}{1 + e^{-z}}\).
    • Behavior of \(g(z)\):
      • If \(z\) is a large positive number (e.g., 100), \(g(z) \approx 1\).
      • If \(z\) is a large negative number (e.g., -100), \(g(z) \approx 0\).
      • If \(z = 0\), then \(g(z) = 0.5\).

    Model Representation¶

    The model is represented as \(f_{\vec{w},b}(\vec{x}) = g(\vec{w} \cdot \vec{x} + b) = \frac{1}{1 + e^{-(\vec{w} \cdot \vec{x} + b)}}\).

    • Interpretation: The output is interpreted as the probability that the input \(\vec{x}\) belongs to Class 1.
    • Example: If \(f_{\vec{w},b}(\vec{x}) = 0.7\), there is a 70% chance the target \(y\) is 1.

    3. Decision Boundaries¶

    The decision boundary is the line or surface that separates the two classes.

    • Threshold: A standard threshold of 0.5 is used for classification:
      • Predict \(y=1\) if \(f_{\vec{w},b}(\vec{x}) \ge 0.5\) (which occurs when \(\vec{w} \cdot \vec{x} + b \ge 0\)).
      • Predict \(y=0\) if \(f_{\vec{w},b}(\vec{x}) < 0.5\) (which occurs when \(\vec{w} \cdot \vec{x} + b < 0\)).
    • Linear Boundaries: In a two-feature set (\(x_1, x_2\)), the boundary is a straight line (e.g., \(x_1 + x_2 = 3\)).
    • Non-linear Boundaries: By using polynomial features (e.g., \(x_1^2 + x_2^2 = 1\)), the model can create complex, curved decision boundaries such as circles, ellipses, or irregular shapes to fit non-linear data patterns.

    4. Cost Function and Optimization¶

    Why Squared Error Fails¶

    Using the squared error cost function (standard in linear regression) for logistic regression results in a non-convex function. This means the surface has many local minima, making it difficult for gradient descent to find the global minimum.

    Maximum Likelihood Estimation (MLE)¶

    Logistic regression parameters are found using the MLE framework, which seeks the weights that maximize the likelihood of observing the training data.

    • Likelihood of a point: \(P(y|x) = \hat{y}^y(1-\hat{y})^{1-y}\).
    • Log-Likelihood: Taking the log of the likelihood over the entire dataset simplifies optimization into a summation.

    The Logistic Loss Function (Binary Cross-Entropy)¶

    To minimize error, we use the negative log-likelihood as our loss function:

    • Loss for a single point (\(L\)):
      • If \(y=1\): Loss \(= -\log(f_{\vec{w},b}(\vec{x}))\).
      • If \(y=0\): Loss \(= -\log(1 - f_{\vec{w},b}(\vec{x}))\).
    • Combined Formula: \(L(f, y) = -y\log(f) - (1 - y)\log(1 - f)\).
    • Cost Function (\(J\)): The average of the losses over all \(m\) training examples: \(J(\vec{w},b) = -\frac{1}{m} \sum_{i=1}^{m} [y^{(i)}\log(f_{\vec{w},b}(\vec{x}^{(i)})) + (1 - y^{(i)})\log(1 - f_{\vec{w},b}(\vec{x}^{(i)}))]\).

    Optimization via Gradient Descent¶

    The parameters \(\vec{w}\) and \(b\) are updated simultaneously to minimize \(J\):

    • Update Rule: \(w_j = w_j - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})x_j^{(i)}\).
    • Monitoring learning curves, utilizing vectorization, and applying feature scaling are essential for efficient convergence.

    5. Addressing Overfitting and Underfitting¶

    • Underfitting (High Bias): The model is too simple (e.g., a straight line for curved data) and performs poorly on both training and test sets.
    • Overfitting (High Variance): The model is too complex, fitting noise and random fluctuations in the training data. It performs excellently on training data but poorly on unseen test data.

    Remediation Strategies¶

    1. Collect more training data: Helps the model learn general patterns rather than noise.
    2. Feature Selection: Manually selecting relevant features to reduce complexity.
    3. Regularization: Penalizing the magnitude of parameters to keep the model simple.

    6. Regularization Techniques¶

    Regularization adds a penalty term to the cost function to prevent parameters from becoming too large.

    • L2 Regularization (Ridge):
      • Term: Adds \(\frac{\lambda}{2m} \sum w_j^2\) to the cost function.
      • Effect: Penalizes large weights, encouraging small, smooth coefficients and a stable decision boundary.
      • Geometric Intuition: Acts as a circular constraint.
    • L1 Regularization (Lasso):
      • Term: Adds \(\frac{\lambda}{m} \sum |w_j|\) to the cost function.
      • Effect: Promotes sparsity; some weights become exactly zero, effectively performing automatic feature selection.
      • Geometric Intuition: Acts as a diamond constraint.

    The \(\lambda\) Parameter¶

    • If \(\lambda = 0\): No regularization; high risk of overfitting.
    • If \(\lambda\) is small: Good balance between bias and variance.
    • If \(\lambda\) is very large: Leads to underfitting (high bias) as the model becomes too simple.
    • Note: The bias term \(b\) is usually not regularized.
