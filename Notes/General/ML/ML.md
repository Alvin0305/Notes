### Terminologies
##### Training Set
- Data used to train the model
##### Feature
- input data
- represented as **X**
##### Target
- output data (expected output)
- represented as **y**
#####  Predicted Output
- output of the ML model
- represented as **$\hat{y}$** 
##### Number of training examples
- represented as **m**
##### Single training example
- represented as **(x, y)**
##### Specific training example
- represented as $(x^{(i)}, y^{(i)})$
- means, i-th training data

### Supervised Learning
- We give the `features` and `targets` (`training set`) to the `learning algorithm`. 
- This `learning algorithm` builds a function `f` (known as `hypothesis`)
- We, now give the features to the function f and we get the predicted output $\hat{y}$ from f
##### Linear Regression
$$
f_{w, b}(x) = wx + b
$$
- univariate linear regression => One variable
