### 🌟 1. **Futur Proche (Near Future)**
#### 📌 **Formation**
> **aller (conjugated) + infinitive verb**

| Subject   | Conjugation of "aller" |
| --------- | ---------------------- |
| je        | vais                   |
| tu        | vas                    |
| il/elle   | va                     |
| nous      | allons                 |
| vous      | allez                  |
| ils/elles | vont                   |

#### 📌 **Examples**

| French            | English                  |
| ----------------- | ------------------------ |
| Je vais manger    | I am going to eat        |
| Elle va étudier   | She is going to study    |
| Nous allons jouer | We are going to play     |
| Ils vont voyager  | They are going to travel |

🔹 This tense talks about **things that will happen very soon**.

---
### 🌟 2. **Passé Composé (Past Tense)**
#### 📌 **Formation**
> **auxiliary verb (avoir/être) + past participle**

Most verbs use **avoir**.  
Some verbs (movement verbs) use **être**.
#### 📌 **With AVOIR**
| Verb    | Past Participle |
| ------- | --------------- |
| manger  | mangé           |
| finir   | fini            |
| prendre | pris            |
| voir    | vu              |
| faire   | fait            |

✔ Sentence pattern:
> **Subject + avoir + past participle**

Examples:
- J’ai mangé (I ate / I have eaten)
- Elle a fini (She finished)
- Nous avons vu le film (We saw the movie)
---
#### 📌 **With ÊTRE (motion + reflexive verbs)**
Common verbs: **aller, venir, entrer, sortir, arriver, partir, naître, mourir, tomber, rester**

| French           | English     |
| ---------------- | ----------- |
| Je suis allé(e)  | I went      |
| Elle est arrivée | She arrived |
| Ils sont partis  | They left   |

⚠ When using **être**, the past participle changes for gender and plural:
- masculine singular → allé
- feminine singular → allée
- masculine plural → allés
- feminine plural → allées
Example:
- Elles sont allées → (They went — all girls)
---

#### 🌟 Summary Table

| Tense         | Formula                      | Example                            |
| ------------- | ---------------------------- | ---------------------------------- |
| Futur proche  | aller + infinitive           | Je vais jouer (I am going to play) |
| Passé composé | avoir/être + past participle | J’ai joué (I played)               |
