##### Class P (easy to solve)
- Problems that have a polynomial-time algorithm to solve them

>[!example] 
>Sorting
>Binary Search
>Shortest path
>MST
>Matrix chain multiplication
>DP problems that run on polynomial time

##### Class NP (easy to verify)
- If we give a solution to these problems, then verifying whether the solution is correct takes only polynomial time

>[!example] 
>Subset sum
>Travelling Salesman Decision Problem
>Graph coloring decision problem
>Sudoku

##### NP-Complete (hardest problems inside NP)
- It is in NP
- It is NP-Hard

>[!example] 
>SAT
>3-SAT
>Subset Sum
>0-1 Knapsack
>Hamiltonian Cycle
>Graph Coloring
>Travelling Salesman Problem

##### NP-Hard (at least as hard as NP)
- Problems which are so tough that verification may not be polynomial
